# Дөрвөн бэрх хүнсний дэлгүүр

«Дөрвөн бэрх» хүнсний дэлгүүрийн вэбсайт. Хүнсний ногоо, шинэ сүү болон өдөр тутмын хэрэглээний барааны үнэ, байгаа эсэхийг харуулдаг энгийн мэдээллийн сайт юм. Онлайн захиалга, хүргэлт байхгүй. Худалдан авагчид дэлгүүрт ирж худалдан авна.

## Боломжууд

- Барааны жагсаалт, үнэ (₮)
- **Бэлэн** / **Дууссан** төлөв
- Ангиллаар шүүх, нэрээр хайх
- Дэлгүүрийн зураг, лого
- Утас болон компьютер дээр сайн харагдана

## Файлын бүтэц

```
public/
  index.html      сайтын үндсэн файл
  images/         зураг, лого
wrangler.jsonc    Cloudflare-ийн тохиргоо
README.md         энэ файл
```

## Үнэ, барааны төлөв өөрчлөх

1. GitHub дээр `public/index.html` файлыг нээнэ.
2. Баруун дээд буланд байгаа харандаа (✏️)
